Das hier enthaltene Script wurde zur Erstellung des Datensatzes verwendet
### Versionen
TShark (Wireshark) 4.7.2.
### Anwendungsanweisungen
1. Wireshark/Tshark muss installiert sein
2. ggf. binary anpassen. code verwendet "tshark". wenn es mit diesem command bereits so konfiguriert ist das er aus dem Terminal mit "tshark" aufgerufen werden kann muss hier nichts mehr geendert werden. Ansonsten binary verlinken
3. Pfade anpassen. ganz oben im Script global definiert. isbesondere "PCAP_PATH" für Ordner mit PCAP files und "CONTROL_LOG_PATH" für Control logs
